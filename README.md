# VatSys Colour Profiles

## What, Why, and How?
VatSys controls its basic styling/colours configured in `Colours.xml`. This repo is a collection of various different colour configs from different VatSys profiles. 

### 0. Default
EuroCat X, pale pastels on a light grey bg. From the Australian profile, used in many others. Authentic to Thales EuroCat X (vanilla VatSys, a.k.a. Ancient TopSky).

### 1. Jakarta
Green-on-black. Styled resembling Jakarta's Indra ATM system.

### 2. Curaçao
Black background with orange & blue accents, inspired by JVG's colours in the Dutch Caribbean (TNCF) EuroScope package.

### 3. Mexico Dark
Thales TopSky blue background, from the Mexican dataset. By VATSIM Mexico.

### 4. Mexico Mid
Thales TopSky lighter background, from the Mexican dataset. By VATSIM Mexico.

### 5. Midnight (NZ)
Raytheon, black background, not compatible with dynamic infill (jurisdiction versus not is the same background). Delightful for the lights-off community and the OLED monitor enjoyers.
